# متطلبات API الإشعارات

## نظرة عامة

التطبيق يتوقع من الـ Backend إنشاء إشعارات تلقائياً في الحالات التالية، وعرضها في صفحة الإشعارات مع شارة حمراء على الأيقونة.

## الحالات التي يجب إنشاء إشعار فيها

| الحدث | نوع الإشعار | مثال الرسالة |
|-------|-------------|--------------|
| إرسال طلب صداقة | `friend_request` | "أرسل [اسم] طلب صداقة لك" |
| الموافقة على طلب صداقة | `friend_acceptance` | "وافق [اسم] على طلب صداقتك" |
| تعليق على منشور | `comment` | "علق [اسم] على منشورك" |
| إعجاب بمنشور | `like` / `interaction` | "أعجب [اسم] بمنشورك" |

## نقاط النهاية المستخدمة

### جلب الإشعارات
- **GET** `/notifications`  
  Query: `page`, `limit`, `status` (new | read | all)  
  الاستجابة: `{ "notifications": [ { "id", "type", "sender": { "name" }, "message", "created_at" } ] }`

### عدد الإشعارات غير المقروءة
- **GET** `/notifications/unread-count`  
  الاستجابة: `{ "data": { "count": 5 } }` أو `{ "count": 5 }`

### تعليم إشعار كمقروء
- **POST** `/notifications/:id/read`

### تعليم الكل كمقروءة
- **POST** `/notifications/read-all`

## طلبات الصداقة — الشارة الحمراء

- **GET** `/friends/requests/count`  
  الاستجابة: `{ "data": { "count": 3 } }` — عدد الطلبات المعلقة

التطبيق يعرض شارة حمراء على:
- أيقونة **الأصدقاء** (groups): عند وجود طلبات صداقة معلقة
- أيقونة **الإشعارات**: عند وجود إشعارات غير مقروءة
